Customer Churn Prediction Using IBM SPSS Modeler

📌 Project Overview

Customer Churn Prediction is a data analytics project that aims to identify customers who are likely to stop using a company's products or services. This project uses IBM SPSS Modeler to analyse customer data, identify churn patterns, and support better business decision-making.

Customer retention is important for every business because retaining existing customers helps improve customer satisfaction, revenue, and long-term growth.

🎯 Objectives

- To understand the concept of customer churn.
- To analyse customer-related data.
- To identify factors that influence customer churn.
- To apply predictive analytics using IBM SPSS Modeler.
- To understand how businesses can improve customer retention.

🛠️ Tools and Technologies

- IBM SPSS Modeler
- Microsoft Excel
- CSV Dataset
- Predictive Analytics
- Data Mining
- Decision Tree Classification

📊 Dataset Description

The project uses a customer dataset containing 100 customer records and 18 attributes.

The dataset includes:

- Customer ID
- Gender
- Senior Citizen
- Partner and Dependents
- Tenure Months
- Internet Service
- Contract Type
- Payment Method
- Monthly Charges
- Total Charges
- Technical Support
- Online Security
- Support Tickets
- Churn Status

Target Variable: Churn (Yes/No)

Note: The dataset is synthetically generated for academic and educational purposes. It does not contain actual customer information.

⚙️ Project Methodology

1. Data Collection – Preparing the customer dataset.
2. Data Import – Importing the dataset into IBM SPSS Modeler.
3. Data Preparation – Checking data types, missing values, and unnecessary fields.
4. Data Exploration – Understanding customer characteristics and churn patterns.
5. Model Development – Applying a suitable classification technique, such as a Decision Tree.
6. Result Interpretation – Analysing model output and identifying important churn factors.

📈 Expected Outcomes

- Identification of customers who may leave a service.
- Understanding of factors associated with customer churn.
- Better understanding of predictive modelling.
- Insights to support customer retention strategies.

💡 Business Applications

Businesses can use customer churn prediction to:

- Improve customer satisfaction.
- Develop customer retention strategies.
- Provide personalised offers.
- Improve customer support.
- Reduce customer loss.
